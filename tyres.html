How to use

  1. Enter front and rear axle loads in kg. A weighbridge ticket is best.
  2. Paste the sidewall of the tyre you fitted, or type the load index. Default is the same size on both axles.
  3. Check the load/pressure chart (C-type at 3.75 bar is the ETRTO commercial default). Switch to 4.50 bar if that is what the sidewall says.
  4. Read the cold front and rear figures above. If the tyre cannot carry the load, this page shows a fail — it will not suggest an unsafe pressure.

Tyres FAQ

Where do these cold pressures come from?

Two public industry sources, not a scraped maker catalogue:

  • The ETRTO / ISO load-index table (for example load index 109 = 1,030 kg).
  • The ETRTO / ISO load–pressure relationship used to build inflation charts: load ÷ reference load = (pressure ÷ reference pressure)0.8. Rearranged, pressure = reference pressure × (your load ÷ load-index kg)1.25.

Reference pressures: 2.50 bar passenger standard load, 2.90 bar XL, 3.75 bar ETRTO C-type commercial (375 kPa), and an optional 4.50 bar van/LT table when the sidewall says the load index is at 65 PSI. This is not a named Continental, Michelin or OEM fitment table for one model.

Cold vs hot — which should I use?

These figures are cold only. Cold means the van has been parked for a few hours, not just off a motorway. Pressure rises as tyres warm up. Do not let air out of a hot tyre to “match” this page — that is the hot-pressure trap.

Why does a non-OEM size need a new pressure?

The door sticker is written for the original tyres. A different size or load index needs the new tyre’s load/pressure table at your axle loads. Copying the old sticker can under- or over-inflate the new rubber.

What if the tyre cannot carry the axle load?

This page shows a clear fail and will not suggest a pressure above the chart maximum or above the load index. Fit a higher load-index tyre, or lose weight. A fitter and the vehicle plate win.

What does 109/107 mean?

Load indexes. The first number is one tyre on that corner (usual UK motorhome: two tyres on the axle). The second is for dual wheels. Most campers only need the first number.

Is this a substitute for the maker or a fitter?

No. Planning estimate only. If the size or load index is outside the table, this page refuses to invent a number. Confirm with the tyre maker’s published chart and a fitter.

How does this sit with the payload calculator?

Use the payload calculator for MAM and kit. Use this page once you know (or estimate) axle loads and have fitted a different tyre.
