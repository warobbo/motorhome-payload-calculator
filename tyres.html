How to use

  1. This is for non-OEM sizes. The door sticker is for the old size.
  2. Paste the sidewall (example already filled: LT265/65R17 120/117S). The page detects LT vs C vs CP vs P-metric and reads the load index.
  3. Enter front and rear axle loads in kg from a weighbridge. Or use the clearly labelled estimate from total laden weight + front/rear split % — that still becomes axle loads, not “payload remaining”.
  4. Read the headline: Front cold and Rear cold in bar and PSI. The table is kg per axle — compare your axle load to the Single column (CP uses separate front and rear columns). Only 15–18″ wheels. If the size or load index is not in the table, or the axle is over the last step → Fail, no invented pressure.
  5. See Sources we use for which brands are in the book today.

Tyres FAQ

Where do these cold pressures come from?

From the published table for that tyre family:

  • LT 15–18″ (including General Grabber LT265/65R17 120/117S): TRA-standard values as published in Continental Tyre Databook (General/Continental brands). 2025 row used for LT265/65R17 where it differs from older books. The table is kg per axle. A typical motorhome uses the Single (S) column. Cold pressure is the lowest bar step that covers the load.
  • C van tyres on 15–18″: the same book’s Van (ETRTO C) steps when that size and load index are listed. Otherwise the ETRTO C-type load/pressure relationship (load index at 3.75 bar, or 4.50 bar if you switch).
  • CP camping / motorhome tyres on 15–18″: the book’s VanContact Camper front-axle and rear-axle columns (ETRTO camping). Not the plain C table. A size or load index we do not have is refused.
  • Rim not 15–18″, or a size / load index we do not have → refused. No invented pressure. No mixing of wrong tables or a different LI.
  • Sources we use names the brands we have today and the ones coming later. We do not claim Michelin, Goodyear, BFGoodrich or Yokohama tables yet.

Official LT 265/65 R 17 Load Range E, LI 120/117 S, measuring rim 8J — load capacity kg per axle:

  • 2.5 bar — Single 1490 / Dual 2735
  • 3.0 bar — Single 1720 / Dual 3160
  • 3.5 bar — Single 1950 / Dual 3580
  • 4.0 bar — Single 2170 / Dual 3980
  • 4.5 bar — Single 2380 / Dual 4375
  • 5.0 bar — Single 2590 / Dual 4760
  • 5.5 bar — Single 2800 / Dual 5140

Example: 1800 kg front needs 3.5 bar (1950 covers; 3.0 only 1720). 2100 kg rear needs 4.0 bar (2170 covers; 3.5 only 1950). Dual (D) only if you select dual wheels on that axle. A fitter and the maker’s own chart still win.

Which brands do you have tables for?

Today: Continental / General Tyre Databook (Car · 4x4 · Van) for the LT, C and CP sizes we list. Pressures are from that published book, not guesses.

Coming later: Michelin (C/LT), then Goodyear Wrangler (LT), then BFGoodrich / Yokohama using industry TRA tables — each clearly labelled when added.

If your size, brand or load index is not listed, this page refuses a number. We will not invent one. Always check pressures cold, stay within the rim maximum, and weigh the axles when you can.

Why not the old US lb/PSI table, or the C-type formula?

The old page used a US TRA extract in pounds per tyre at PSI, then divided the axle load by 2. That gave about 45 / 55 PSI for 1800 / 2100 kg — too low against Wayne’s official PDF. The C-type 3.75 / 4.50 bar formula is only for C-marked European van tyres. General Grabber LT265/65R17 120/117S is an LT tyre; this page now uses the Continental / General databook kg-per-axle steps.

Cold vs hot — which should I use?

These figures are cold only. Cold means the van has been parked for a few hours, not just off a motorway. Pressure rises as tyres warm up. Do not let air out of a hot tyre to “match” this page.

Why does a non-OEM size need a new pressure?

The door sticker is written for the original tyres. A different size or family needs the new tyre’s load/inflation table at your axle loads. Copying the old sticker can under- or over-inflate the new rubber.

What if the tyre cannot carry the axle load?

This page shows a clear fail and will not suggest a pressure if the axle load is over the last published step for that size (for Wayne’s Grabber that is 2800 kg on the Single column at 5.5 bar). Fit a higher-capacity tyre, or lose weight. A fitter and the vehicle plate win.

What does CP mean on a motorhome tyre?

CP is Camping Pneu — a motorhome / camper tyre with ETRTO special camping load capacities. It is not the same as a plain C van tyre. This page uses the Continental databook’s CP front (FA) and rear (RA) kg-per-axle columns for driving cold pressure. The rear column needs a higher pressure for the same load (Continental also notes a higher rear camping pressure, about +0.75 bar on some fact sheets). When the van is parked, CP rules can allow a temporary higher load at a higher pressure — that parked / site figure is not what this page prints. A fitter and the maker’s own camping table still win.

What does 120/117 mean?

Load indexes on the sidewall. Each load index is a separate row in the table — 225/75R16C LI 116, 118 and 121 are three entries, not one blob. We will not silently use another LI. The databook Single column is already kg for the whole axle with two tyres. Do not divide your axle load by 2 and then look up a US lb-per-tyre table. Dual wheels use the Dual column only if you select 4 tyres on that axle.

Is this a substitute for the maker or a fitter?

No. Planning estimate only. If the size is outside the tables on this page, it refuses to invent a number. Confirm with the tyre maker’s published chart and a fitter.
